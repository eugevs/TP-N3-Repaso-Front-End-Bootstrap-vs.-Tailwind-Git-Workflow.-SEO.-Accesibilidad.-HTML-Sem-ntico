# Explorando lugares

Sitio web front-end de turismo y senderismo desarrollado para consultar rutas de caminatas, recomendaciones de equipamiento, ver fotos de la comunidad y conocer detalles de los senderos.

---

## Tecnologías utilizadas
- HTML5 y CSS3
- Bootstrap
- Prettier (formateo de código)
- Google Lighthouse (auditorías de rendimiento y accesibilidad)
- Squoosh (optimización de imágenes a `.webp`)
- Git y GitHub (control de versiones y GitHub Pages)

---

## Estructura y Vistas
- **Inicio (`index.html`):** Presentación principal y accesos rápidos.
- **Caminatas (`caminatas.html`):** Lista de recorridos y senderos disponibles.
- **Detalle de Ruta (`ruta-detalle.html`):** Información detallada del sendero y mapa.
- **Equipamiento (`equipamiento.html`):** Mochilas, calzado y equipo recomendado.
- **Galería (`galeria.html`):** Sección para ver y compartir fotos.
- **Contacto (`contacto.html`):** Formulario de contacto.
- **Login y Registro (`login.html` / `registro.html`):** Vistas de acceso de usuario.
- **Sobre el sitio (`nosotros.html`):** Información sobre la plataforma.
- **Perfil (`perfil.html`):** Resumen de actividad y rutas del usuario.

---

Los puntajes de rendimiento, accesibilidad y SEO medidos con Lighthouse para cada vista están documentados en el archivo [`auditoria.md`](./auditoria.md).
